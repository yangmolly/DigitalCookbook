# iOS Bootcamp Final Project: Digital Cookbook

This digital cookbook is meant to help users find recipes using the ingredients they already have on hand in hopes of saving time and reducing food waste.

## Tools

- ForEach - used to code the rows for recipes all at once, instead of individually
- @State - remembers what the user types into the searchbar and sets the toggle to
- User input - text field for user to type food and toggle to choose pantry inclusion
- @Binding - communication between searchbar and main screen
- API - Spoonacular

## Features

- Allows users to type in exactly what ingredient they want to utilize first
- Easy to navigage
- Quick results
